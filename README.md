# Cálculo del consumo de gasolina de una motocicleta

## Descripción

Este proyecto fue desarrollado en Python para resolver un problema de la vida real mediante el uso de una función.

El programa permite calcular el consumo aproximado de gasolina de una motocicleta utilizando la distancia recorrida y el dinero utilizado para comprar combustible.

## Datos utilizados

Kilómetros recorridos: 335 km
Dinero utilizado: $8,30
Precio de gasolina Extra: $3,24 por galón
Conversión: 1 galón = 3,785 litros

## Funcionamiento

La función `calcular_consumo()` recibe dos parámetros:

* `kilometros`
* `dinero`

Primero se calcula la cantidad de galones de gasolina comprados. Después se convierten los galones a litros y finalmente se calcula cuántos kilómetros puede recorrer la motocicleta por cada litro de gasolina.

## Resultado

Con 335 kilómetros recorridos y $8,30 de gasolina, el programa obtiene un consumo aproximado de:

**34,55 km/L**
